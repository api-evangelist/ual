Ualá is a Latin American fintech founded in Argentina in 2017, offering a neobank super-app in Argentina and Mexico (as Ualá ABC). Its merchant arm, Ualá Bis, publishes the API Cobros Online v2 — an online-payments checkout API with hosted payment links, order retrieval and listing, refunds, and webhook status notifications — documented at [developers.ualabis.com.ar](https://developers.ualabis.com.ar/) with official Node.js and PHP SDKs ([GitHub: Uala-Developers](https://github.com/Uala-Developers)).

Backed by: bessemer-venture-partners

This repository profiles Ualá's API surface for the API Evangelist network: see `apis.yml` for the index and `openapi/`, `asyncapi/`, `errors/`, `conventions/`, `authentication/`, `sandbox/`, `packages/`, `skills/`, and `security/` for captured artifacts.
